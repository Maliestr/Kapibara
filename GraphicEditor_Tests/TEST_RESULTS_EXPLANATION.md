# Что проверяют тесты и какие результаты они показывают

## Общее описание

Тесты проверяют **логику перемещения фигур (shapes) на Canvas** в вашем графическом редакторе. Они имитируют функциональность перетаскивания элементов мышью и проверяют, что:

1. ✅ Фигуры корректно перемещаются на новые координаты
2. ✅ Фигуры ограничены границами рабочей области
3. ✅ Нельзя перемещать элементы, которые не находятся на Canvas
4. ✅ Можно перемещать несколько фигур одновременно

---

## Детальное описание каждого теста

### 🟢 Тест 1: `Test_Move_Ellipse_Success`

**Что проверяет:**
- Успешное перемещение эллипса на новые координаты

**Входные данные:**
- Эллипс размером 50x50 пикселей
- Начальная позиция: (100, 100)
- Попытка переместить на: (200, 200)

**Ожидаемый результат:**
- ✅ Тест **ПРОЙДЕН** (зеленый)
- Эллипс должен быть перемещен на координаты (200, 200)
- Метод `SimpleMoveShape` должен вернуть `true`

**Что выводится:**
```
✅ Test_Move_Ellipse_Success - ПРОЙДЕН
   Фигура должна перемещаться
   Позиция X: 200 (ожидалось: 200)
   Позиция Y: 200 (ожидалось: 200)
```

**Если тест падает:**
- ❌ Тест **ПРОВАЛЕН** (красный)
- Сообщение: "Фигура должна перемещаться" или "Ожидалось 200, получено [другое значение]"

---

### 🟢 Тест 2: `Test_Move_Ellipse_Outside_Left`

**Что проверяет:**
- Ограничение перемещения левой границей Canvas

**Входные данные:**
- Эллипс размером 50x50 пикселей
- Начальная позиция: (100, 100)
- Попытка переместить на: (-10, 100) - **отрицательная координата X**

**Ожидаемый результат:**
- ✅ Тест **ПРОЙДЕН** (зеленый)
- Эллипс должен быть ограничен левой границей
- Финальная позиция X должна быть **0** (не -10!)
- Позиция Y остается 100

**Что выводится:**
```
✅ Test_Move_Ellipse_Outside_Left - ПРОЙДЕН
   Фигура должна быть ограничена
   Позиция X: 0 (ожидалось: 0) - прижата к левой границе
   Позиция Y: 100 (ожидалось: 100)
```

**Если тест падает:**
- ❌ Тест **ПРОВАЛЕН** (красный)
- Сообщение: "Ожидалось 0, получено [другое значение]"
- Это означает, что логика ограничения границами работает неправильно

---

```
✅ Test_Move_Multiple_Shapes - ПРОЙДЕН
```

## Детальная информация о проверках

### Проверка границ рабочей области:

Тесты проверяют, что фигуры ограничены:
- **Левая граница:** X ≥ 0
- **Правая граница:** X ≤ (ширина Canvas - ширина фигуры)
- **Верхняя граница:** Y ≥ 40 (WorkAreaTop)
- **Нижняя граница:** Y ≤ (высота Canvas - высота фигуры - 100)

### Проверка валидности элемента:

Тесты проверяют, что:
- Элемент не `null`
- Элемент находится в коллекции `Children` Canvas
- Элемент имеет корректные размеры

## Связь с реальным приложением

Эти тесты проверяют ту же логику, что используется в методе `CanvasShape_MouseMove` в `MainWindow.xaml.cs`:

```csharp
// В реальном приложении (MainWindow.xaml.cs, строка 418):
newLeft = Math.Max(0, Math.Min(newLeft, MainCanvas.ActualWidth - elementWidth));
newTop = Math.Max(WorkAreaTop, Math.Min(newTop, maxTop));
```

Если тесты проходят, значит эта логика работает правильно и в реальном приложении!
